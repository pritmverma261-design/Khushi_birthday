# Khushi Birthday Surprise ❤️

A mobile-first interactive birthday surprise inspired by the interactive birthday-card experience at MyHeartCraft.

## Includes
- Balloon popping interaction
- Candle blow-out/tap interaction
- Personalized birthday cake
- Animated confetti
- Birthday letter
- Two supplied photos
- No backend, account, API, or paid service required

## Run locally
Open `index.html` in a browser.

## Deploy free
Upload all files/folders to a GitHub repository and enable **GitHub Pages** from Settings → Pages → Deploy from branch → `main` → `/root`.

Then share the GitHub Pages URL.

## Personalization
Edit the text in `index.html` if you want to change the message.
